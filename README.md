# Israel-Palestine Social Pulse

This project is a real-time social media analytics dashboard focused on the Israel-Palestine conflict. The dashboard visualizes sentiment, engagement, trending topics, emotional pulse, and geographic sentiment distribution using tweet-like data generated by a Python script.

## Features
- Real-time sentiment and engagement tracking
- Emotion analysis using a pie chart
- Geographic sentiment visualization on an interactive map
- Topic engagement analysis
- Trending topic monitoring
